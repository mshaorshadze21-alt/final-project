
# PetCare — შინაური ცხოველების მოვლის პლატფორმა

PetCare არის React.js-ის გამოყენებით შექმნილი ვებპლატფორმა, რომლის მიზანია შინაური ცხოველების პატრონების, მომვლელებისა და ცხოველებთან დაკავშირებული სერვისების ერთ ციფრულ სივრცეში გაერთიანება.

პროექტი შექმნილია Frontend Development-ის სასწავლო კურსის ფარგლებში და წარმოადგენს სრულფასოვანი პლატფორმის საწყის, სადემონსტრაციო ვერსიას.

 **[Live Demo — PetCare](https://final-project-bay-mu-80.vercel.app/)**

## 📌 პროექტის იდეა და მიზანი

PetCare-ის მთავარი იდეაა შინაური ცხოველების მოვლასთან დაკავშირებული სერვისების მოძიების გამარტივება.

პლატფორმა განკუთვნილია სამი ძირითადი ჯგუფისთვის:

- **ცხოველების პატრონები** — ადამიანები, რომლებიც ეძებენ ცხოველის მოვლისა და გასეირნების მომსახურებებს.
- **მომვლელები და გამსეირნებლები** — მომსახურების დამოუკიდებელი მიმწოდებლები.
- **პარტნიორი ბიზნესები** — ვეტერინარული კლინიკები, გრუმინგის სალონები, ზოომაღაზიები და ცხოველების სასტუმროები.

პროექტი პირველ ეტაპზე ორიენტირებულია საქართველოს ბაზარზე.

## ინსტალაცია და გაშვება

პროექტის გასაშვებად საჭიროა Node.js და npm.

### 1. პროექტის ჩამოტვირთვა

ჩამოტვირთეთ პროექტის ფაილები GitHub-იდან და გახსენით საქაღალდე ტერმინალში ან Visual Studio Code-ში.

### 2. დამოკიდებულებების ინსტალაცია

```bash
npm install
```

### 3. განვითარების სერვერის გაშვება

```bash
npm run dev
```

ტერმინალში გამოჩნდება ლოკალური მისამართი, რომლის გახსნაც შესაძლებელია ბრაუზერში.

### 4. Production ვერსიის აწყობა

```bash
npm run build
```
